No file handy?
1. Parse

The Java service streams your file, infers each column's type and counts distinct values.

2. Suggest

The agent sees the schema and twenty sample rows, never the whole file, and returns three chart specs.

3. Render

Each spec is checked against the real schema, then aggregated over every row before it is drawn.
